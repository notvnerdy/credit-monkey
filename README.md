# Credit Monkey - Professional Credit Repair Website

A modern, responsive credit repair website built with Bootstrap 5, featuring professional design, smooth animations, and a clean user experience.

## Features

- **Bootstrap 5 Framework**: Stable, production-ready framework
- **Responsive Design**: Works perfectly on all devices
- **AOS Animations**: Smooth scroll animations
- **Bootstrap Icons**: Comprehensive icon library
- **3 Pricing Plans**: $99, $159 (featured), $199/month
- **FAQ Accordion**: Bootstrap collapse component
- **Trust Badges**: BBB, Google, Yelp
- **Client Login**: Direct link to secure client portal
- **Smooth Scrolling**: Enhanced navigation experience

## Sections

1. **Hero**: Eye-catching intro with animated credit score
2. **Stats**: 4 animated counters with key metrics
3. **Services**: 4 detailed service cards
4. **How It Works**: 4-step process
5. **Pricing**: 3-tier pricing with featured plan
6. **Testimonials**: Real client reviews
7. **FAQ**: Common questions with accordion
8. **CTA**: Strong call-to-action section
9. **Footer**: Comprehensive links and legal info

## Technologies

- HTML5
- Bootstrap 5.3.2
- Bootstrap Icons 1.11.3
- AOS (Animate On Scroll) 2.3.1
- Google Fonts (Inter, Poppins)
- Custom CSS & JavaScript

## Setup

1. Clone or download the project
2. All dependencies are loaded via CDN
3. Open `index.html` in a browser
4. No build process required!

## Customization

### Colors
Edit CSS variables in `assets/css/styles.css`:
```css
:root {
    --primary-color: #2563eb;
    --secondary-color: #10b981;
    --dark-color: #1e293b;
    --light-bg: #f8fafc;
}
```
