S2S Postback Reference

Postback URL:
https://track.flexlinkspro.com/da.ashx?advertiserid=...&clickid=...&orderamount=...&ordernumber=...

Parameter Description Required
advertiseridUnique FlexOffers account IDYes
clickidFlexOffers unique click identifier (from refid)Yes
orderamountTotal sale amount (before taxes/shipping)Yes
ordernumberOrder number or unique sale IDYes
couponCoupon code (max 300 chars)No
currencyISO 4217 currency codeNo
geoISO 3166 country codeNo
commissionidAdvanced commission IDNo
order_itemsProduct data array (sent in POST body as JSON)No
